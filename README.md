# AI CORE Android

Application Android AI CORE en français, conçue pour être compilée par GitHub Actions.

## Fonctions
- Assistant mobile avec messages préparés et confirmation manuelle avant envoi.
- Calculatrice, notes locales, météo, cartes, recherche, agenda, YouTube et Spotify.
- Dictée française via le moteur vocal Android, après autorisation du microphone.
- Les liens vers les autres applications s’ouvrent sur le téléphone.

## Télécharger l’APK
1. Ouvre l’onglet **Actions** du dépôt.
2. Sélectionne le dernier workflow **Build AI CORE APK**.
3. Télécharge l’artefact **AI-CORE-Android-APK** et extrais le fichier APK.
4. Ouvre l’APK sur Android et confirme l’installation si le téléphone le demande.

L’APK debug est destiné aux essais. L’envoi de messages reste manuel : AI CORE prépare le brouillon puis ouvre l’application choisie.
